# Step 4.9 — Existing Character Tests Migration

## Goal

Migrate existing Character-focused tests from the legacy monolith assumptions to
the split base Character + profile model, and retire `app.models.character.Character`
as the primary domain type where safe.

Remove or isolate the temporary legacy bridge once runtime paths no longer depend
on it.

## Existing Context

- `tests/test_characters.py` (~22 tests) — HTTP CRUD against monolith
- `tests/test_character_tools.py` (~26 tests) — tools against monolith
- `tests/test_character_domain_boundaries.py` — split domain + bridge
- AI tests (`test_ai_integration.py`, etc.) exercise Character via tools
- Legacy bridge exists for migration compatibility

## In Scope

- Update character HTTP and tool tests for split model semantics
- Retire or quarantine legacy monolith domain usage in production paths
- Remove `legacy_character_bridge` when no longer required (or move to test-only shim)
- Architecture checks: no D&D fields on `GenericCharacter`
- Confirm `app.models.character.Character` reduced to shim or removed

## Out of Scope

- New product features
- Campaign / User tests
- Rewriting unrelated AI infrastructure tests except Character path updates

## Required Interfaces

Production code after this step should treat `GenericCharacter` + profiles as
canonical; legacy `Character` absent or deprecated with explicit migration note.

## Data/Persistence impact

None beyond prior steps; tests use same refactored persistence.

## Acceptance Criteria

1. Character HTTP and tool tests assert split model behavior.
2. No production path requires monolithic `Character` as primary domain.
3. Legacy bridge removed or documented as test-only if retained briefly.
4. Architecture grep/check prevents D&D mechanics on base Character type.
5. Full suite green.

## Required Tests

- Migrated `test_characters.py` and `test_character_tools.py`
- Architecture invariant tests updated
- Bridge removal does not break suite

## Architecture Constraints

- Follow `.cursor/rules/architecture.mdc` and `scripts/check_architecture.sh`.
- Generic AI layers unchanged.
